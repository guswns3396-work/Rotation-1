# Detailed preprocessing notes

Exhaustive notes on every preprocessing step, from the raw exports to the analysis tables, written by Claude from the
code, the data READMEs and the audit record. They are meant to be complete rather than short: the curated text one
folder up picks what matters and links here for the detail.

Conventions:

- Every rule says whether it is **applied** in the files the current results use, or was **staged or proposed and
  not applied**.
- Every claim names its source: a code file and function, a README section, or a dated decision.
- Headings are stable, so links to `file.md#heading` keep working.
- Methods and aggregate counts only. No participant IDs and no rows from the study files.
