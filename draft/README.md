# Drafts

Working text for the presentation and the report, in three parts:

| Folder | What goes in it |
|---|---|
| `1. Preprocessing and model/` | How the data were prepared and what model is fitted. The short, curated version lives here; `LLM slop/` underneath holds the exhaustive notes it links to. |
| `2. Results/` | Results to show, with the figure or table each one comes from. |
| `3. Problems/` | Known problems, open questions and things not yet checked. |

Text that is ready moves into `presentation/` or `report/` at the root of the repository.

The repository is public. No participant-level data goes here (no IDs, no rows from the study files), and results
are study results: check with Drew before committing them.
